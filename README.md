## ✨ What's This All About?

Ever had a prop (an item or object) get stuck to your character in FiveM? It's super annoying, right? 😤 Well, say goodbye to those frustrations! This lightweight script lets you instantly remove all those clingy objects with just one simple command. No more relogging, no more headaches! 

## 🎁 Features

- 🚀 **Super Fast** - Removes stuck props in milliseconds
- 🎯 **One Command** - Just type `/propfix` and you're good to go!
- 🪶 **Lightweight** - Barely uses any resources
- 🔧 **Zero Configuration** - Works right out of the box
- 🧹 **Complete Cleanup** - Removes all attached objects and clears tasks
- 🛡️ **Safe & Reliable** - No risk to your server or player data

## 📦 Installation

1. **Download** this resource
2. **Drop** it into your `resources` folder
3. **Add** this line to your `server.cfg`:
   ```cfg
   ensure fivem_lero_prop_fix
   ```
4. **Restart** your server and you're done! 🎉

## 🎮 Usage

It couldn't be easier! Just type this in-game:

```
/propfix
```

That's it! All stuck props attached to your character will be instantly removed. ✨

## 🔍 How It Works

When you run the command, the script:
1. 🔎 Scans all objects in the game pool
2. ✂️ Detaches anything stuck to your character
3. 🗑️ Safely deletes those pesky props
4. 🧼 Clears any lingering tasks

All of this happens in the blink of an eye!
